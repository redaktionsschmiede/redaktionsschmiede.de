Secret Masker

KI-Dienste wie ChatGPT und Claude helfen im Redaktionsalltag: ordnen, zusammenfassen, umformulieren. Wer aber Texte in ein fremdes System einfügt, gibt Daten aus der Hand – personenbezogene Angaben, Zugangsdaten, interne Adressen, Pfade und Rechnernamen wandern mit.

Der Secret Masker markiert solche Stellen, bevor der Text den Browser verlässt, und ersetzt sie durch Platzhalter wie [E-MAIL] oder [API_KEY]. Kontext und Struktur bleiben erhalten, die heiklen Werte nicht. So lässt sich der Nutzen von Sprachmodellen ausschöpfen, ohne die Datensicherheit zu beschädigen.

So funktioniert es: Gesamten Text einfügen, Vorschau prüfen, einzelne Funde mit ✕ ablehnen oder mit ✓ wieder maskieren, Endergebnis kopieren. Standard: alles maskiert.

1 · Eingabe (gesamten Text hier einfügen)
2 · Vorschau –

Farbig unterlegt = wird maskiert · Grau unterlegt = abgelehnt (bleibt im Klartext) · Buttons direkt an der Stelle: ✕ ablehnen, ✓ wieder maskieren

Datenschutz: Der eingefügte Text wird ausschließlich in diesem Browser verarbeitet und nicht gesendet. Das Werkzeug setzt keine Cookies, nutzt kein localStorage, sessionStorage oder IndexedDB und macht nach dem Laden keine Netzwerkaufrufe; eine Sicherheitsrichtlinie der Seite (Content-Security-Policy) verbietet sie zusätzlich. Diese Seite lädt keine externen Ressourcen – kein Stylesheet, keine Schrift, kein Tracker; Design und Logik liegen vollständig im Quelltext, der offen ist: masker/index.html auf GitHub (Apache-2.0).

    


    

      
Grenzen: Erkannt werden API-Keys und Tokens, Passwörter und Credentials, IDs und Hex-Strings, E-Mail-Adressen, Usernamen, Dateipfade, IP-Adressen (alle IPv4, auch interne), Webadressen, IBANs und Telefonnummern. Namen von Personen, Orte und andere Angaben im Fließtext werden nicht erkannt. Eine automatische Erkennung ist nie vollständig: Prüfen Sie das Ergebnis, bevor Sie Text an einen fremden KI-Dienst senden. Das Werkzeug wird ohne Gewähr bereitgestellt.
