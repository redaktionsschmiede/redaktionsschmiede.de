🔒 Secret Masker

Zu maskierende Stellen sind farblich unterlegt – direkt im Text annehmen (✕) oder ablehnen (✓ bei grauen Stellen). Standard: alles maskiert.

Farbig unterlegt = wird maskiert · Grau unterlegt = abgelehnt (bleibt im Klartext) · Buttons direkt an der Stelle: ✕ ablehnen, ✓ wieder maskieren

🔒 Datenschutz: Der eingefügte Text wird ausschließlich in diesem Browser verarbeitet und nicht gesendet. Das Tool setzt keine Cookies, nutzt kein localStorage, sessionStorage oder IndexedDB und macht nach dem Laden keine Netzwerkaufrufe; eine Sicherheitsrichtlinie der Seite (Content-Security-Policy) verbietet sie zusätzlich. Der Quellcode ist offen: masker/index.html auf GitHub (Apache-2.0).

      


      

        
Grenzen: Erkannt werden API-Keys und Tokens, Passwörter und Credentials, IDs und Hex-Strings, E-Mail-Adressen, Usernamen, Dateipfade, IP-Adressen (alle IPv4, auch interne), Webadressen, IBANs und Telefonnummern. Namen von Personen, Orte und andere Angaben im Fließtext werden nicht erkannt. Eine automatische Erkennung ist nie vollständig: Prüfen Sie das Ergebnis, bevor Sie Text an einen fremden KI-Dienst senden. Das Werkzeug wird ohne Gewähr bereitgestellt.
